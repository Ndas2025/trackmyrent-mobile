# TrackmyRent Design System

## Visual Direction

TrackmyRent should feel calm, trustworthy, and fast for small-business owners. The interface uses a light neutral base, green brand actions, and clear payment status colors.

## Spacing

Use a 4px base grid: `4`, `8`, `12`, `16`, `20`, `24`, `32`, `40`.

## Radius

Cards, inputs, and buttons use `8px`. Small elements can use `6px`. Badges use pill radius.

## Components

- Button: primary, secondary, ghost, danger, loading, disabled.
- Card: white surface, 8px radius, light border, subtle shadow.
- TextField: label, input, helper text, error text.
- Badge: paid, unpaid, frozen, pending, neutral.
- SummaryCard: compact dashboard metric card with colored marker.

## Figma Mapping

Create Figma color styles using the token names above. Create text styles for Title, Section Title, Body, Label, and Caption. Build components with the same variants listed above so design and code stay aligned.
